# rl

Reinforcement Learning (RL) နှင့် Robotics ကို လေ့လာရန် သီအိုရီအကျဉ်းချုပ်များ၊ မြန်မာဘာသာပြန်များ၊ simulation လေ့လာရေးလမ်းညွှန်များနှင့် algorithm implementation အသုံးပြုပုံများကို စုစည်းထားသော repository ဖြစ်ပါတယ်။

## Markdown ဖိုင်စာရင်း
